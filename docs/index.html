Even the AI Reviewers Get Reviewed.

AI hallucinates. The Critic persona evaluates all specialist findings, rejecting false positives and refining actionable feedback before it ever reaches a human.

React Agent: "You should memoize this value using useMemo."
Critic (Analyzing): "The dependency array contains primitives that change every render. Memoizing here actually degrades performance due to overhead."
Action: Publish → REJECTED (False Positive)
